# Aura Alloy · RAZR V3

## Reference and scope

The Motorola-authored V3 GSM user's guide (© Motorola, 2004, dated August 23, 2004) documents the external display, navigation, configurable wallpaper and skins. A historical mirror is available at [Motorola MOTORAZR V3 user manual](https://manuzoid.com/manuals/2JDW8-Motorola%20MOTORAZR%20V3%20User%20manual). The original manual's contents identify display/menu pages 32–38 and skin/theme pages 60–62. Reference checked October 22, 2026.

Aura Alloy interprets the silver clamshell, etched keypad and blue display era through a dark metallic backdrop, pale blue LCD clock, compact monospace labels and bevelled category icons. These are design choices, not claims that one firmware shipped this exact palette. Regional/operator skins varied.

## Artwork

All bundled RAZR visuals are original Kotlin Canvas/Compose code. No manufacturer logo, firmware, wallpaper, ringtone or bitmap is redistributed. Existing user collections remain optional and separate. Unknown apps retain their real icons; “Normales” uses every app's own icon. Nothing remains the default.

The theme changes appearance only. It keeps Aura's launcher arrangement and editable dashboard. High contrast replaces the decorative backdrop; no new animation loop, permission or network access is introduced.
