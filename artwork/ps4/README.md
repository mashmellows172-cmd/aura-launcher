# Current direction · beta32

PS4 now preserves Aura's vertical list, persistent search and alphabet navigation. The separate console shell and PSN actions described below belong to beta31 and have been retired after user feedback. Published Sony PNGs remain as source references; release resource shrinking excludes unused assets. Noto Sans, native waves and the avatar motif remain active.

# PS4 resources and fidelity

Sony published PNG glyphs are preserved byte-for-byte; provenance, dimensions and hashes: official-assets.json. They are copyrighted Sony resources referenced for this private personal theme, not Aura originals and not covered by the code MIT license. Their native dimensions are17–27px: these are NOT an HD icon kit. Runtime tint makes the guide glyphs legible against the dark console background. Native app identities and personal overrides remain the content covers.

Noto Sans Regular/Light from https://github.com/notofonts/noto-fonts (hinted/ttf/NotoSans), SIL OFL1.1 in NOTO-LICENSE.txt. SST was not bundled.

Layout references: https://manuals.playstation.net/document/en/ps4/basic/screens.html and its osd_home.jpg, osd_function.jpg, osd_quickmenu.jpg. The live manual states system software13.50+, so screenshots substantiate the Dynamic Menu structure but do not certify firmware9.x pixel identity. Main-menu blue waves are original native drawing, not a video ripped from firmware. Existing profile image is retained.

Functions map to real operations: notifications to Android shade, events to calendar, music to active media app, library to installed Android apps, settings to Aura, Store to the official website. Friends/messages/party/trophies explicitly offer PlayStation App; Aura does not implement PSN or invent account data. Power-shaped action is labelled Bloquear and uses the already-configured optional lock service.

Remaining fidelity gap: officially sourced high-resolution/vector icons and independently version-identified9.x screenshots. Do not claim exact/HD reproduction until these are obtained and visually compared.
